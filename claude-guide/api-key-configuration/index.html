Claude Code API Key 配置

Claude Code的认证配置应先确定账户路径，再处理变量和密钥。本专题说明如何核对组织归属、避免秘密进入仓库、在CI中限制访问、轮换或撤销凭证，并把实际用量与正确费用来源对齐。订阅登录、Console及第三方平台的认证机制不能随意混用，验证时只需使用无敏感资料的小任务。

Claude Code先选订阅登录还是API认证

团队同时有个人订阅与Console使用权限。查看当前官方支持的认证路径，通过只保留本次需要的凭证来源确认使用者知道请求由何种账户计费。
