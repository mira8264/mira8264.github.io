VS Code 怎么配置 Claude Code

VS Code中的Claude Code既涉及扩展面板，也可能涉及独立CLI和远程工作区。本专题说明如何确认官方扩展来源、实际运行目录、文件引用、终端错误、计划与差异，以及会话恢复和快捷键冲突。安装界面出现不代表项目依赖或远程权限已经就绪，应分别验证账户、文件和项目命令。
