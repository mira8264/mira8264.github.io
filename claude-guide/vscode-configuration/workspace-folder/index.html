VS Code 怎么配置 Claude Code / 指南 03

VS Code打开Claude Code前选对目录

本机有项目旧副本和远端当前副本。用文件树核对目标文件，通过先读取一个已知文件验证确认助手处理的是预期仓库版本。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    确认仓库根目录与当前分支，查看打开目录的真实路径与当前提交，避免同名项目副本造成误操作。

  2. 02

    用文件树核对目标文件，从文件树找到已知目标并读取一段内容，与工单引用的版本进行比对。

  3. 03

    明确多根工作区中的任务范围，多根工作区注明允许修改的根目录，不能默认所有打开文件都属于同一任务。

  4. 04

    先读取一个已知文件验证，先请助手说明文件位置和已有内容，确认无误后再允许进行有范围的修改。

怎样判断已完成

助手处理的是预期仓库版本。

容易忽略的地方

在同名克隆目录间误认工作区。

示例与记录方式

本机有repo-old，远端有repo-current，两者都有src/app.ts。验证先要求读取已知标记和真实路径，记录分支与提交；文件名相同但内容不同说明工作副本需要重新确认。
