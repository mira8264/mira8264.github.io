VS Code Claude Code扩展升级验收

升级后重新核对插件与CLI是否仍为不同版本。查看官方更新说明，通过运行同一小任务和差异检查确认原有关键工作流程仍能完成。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    记录旧版本和关键任务样本，保存当前扩展与CLI分别的版本，选一个能覆盖日常关键步骤的小样本。

  2. 02

    查看官方更新说明，重点阅读登录、上下文和界面入口相关变更，不把升级图标出现当作完成验收。

  3. 03

    升级后核对面板与认证，升级后分别确认面板可打开及预期账户可用，状态异常时先保留错误证据。

  4. 04

    运行同一小任务和差异检查，重复同一读取与小修改任务并审查差异，确认变化没有破坏原先工作流程。

怎样判断已完成

原有关键工作流程仍能完成。

容易忽略的地方

升级后只看图标出现没有实际测试。

示例与记录方式

升级样本保留旧扩展版本和一个读取加小改动的公开任务，CLI版本另列。升级后重复同一任务并检查认证、文件引用与差异；图标正常显示但功能未验证时，应保留待验收状态。
