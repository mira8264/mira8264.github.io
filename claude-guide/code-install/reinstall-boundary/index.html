Claude Code重装前保留哪些资料

用项目仓库、本地设置与认证相关文件解决本篇问题：区分项目文件和应用配置，按官方卸载说明选择清理范围。重点防止把删除整个用户目录当成重装步骤，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备项目仓库、本地设置与认证相关文件；列出项目仓库、任务输出与应用配置三类位置，分别决定是否需要备份。

  2. 02

    区分项目文件和应用配置，按官方卸载说明选择清理范围；按官方卸载重装说明确认会清理哪些项目，不能把整个用户目录当成应用数据。

  3. 03

    先验证备份可读取，再执行限定范围清理；重装后逐项检查项目与必要设置恢复情况。

  4. 04

    验收重装后项目数据完整且设置来源可解释：重装只影响选定应用范围，项目文件仍完整，恢复的设置来源与保留原因清楚。

怎样判断已完成

重装只影响选定应用范围，项目文件仍完整，恢复的设置来源与保留原因清楚。

容易忽略的地方

把删除整个用户目录当成重装步骤。

示例与记录方式

示例备份：重装前保留项目仓库与必要设置记录，明确哪些认证资料由本人重新登录，不打包转交给他人。 重装前保存任务输出与配置说明，仓库留在原位置，不将用户主目录递归删除作为清理办法。
