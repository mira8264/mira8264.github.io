Claude Code怎样核对Git Bash路径

用Git安装位置、bash.exe实际路径与官方设置说明解决本篇问题：确认可执行文件存在，再按文档设置正确路径并重开会话。重点防止照抄他人的Program Files路径但本机位置不同，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    从本机Git安装记录找到实际bash.exe文件，记录完整路径；检查是否存在多个Git副本或自定义安装目录。

  2. 02

    对照官方说明设置正确的目标路径，不能把别人Program Files中的位置直接当成本机事实。

  3. 03

    新开会话后用最小Shell任务确认命中目标程序，若仍是旧副本就检查设置与搜索顺序。

  4. 04

    被调用的Git Bash路径与本机真实文件相符，旧副本和自定义目录的冲突已经解释。

怎样判断已完成

容易忽略的地方

照抄他人的Program Files路径但本机位置不同。

示例与记录方式

示例路径记录：Git位于自定义磁盘，先在本机找到bash.exe并核对文件存在，再按官方路径配置说明处理。新会话用小任务确认目标Shell，不复制别人机器上的默认Program Files地址。
