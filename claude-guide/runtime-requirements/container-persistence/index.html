Claude Code容器环境持久化验收

镜像不应包含创建者个人有效凭证。明确代码配置与凭证保存策略，通过核对应保留和应清除的内容确认重建结果符合既定数据边界。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    列出临时层与持久挂载，将代码、配置、缓存和认证按临时层或挂载位置分类，明确各自保留策略。

  2. 02

    明确代码配置与凭证保存策略，凭证采用认可的运行时注入，不把创建者有效个人密钥写进可分发镜像。

  3. 03

    重建一次测试容器，仅在测试容器执行重建，事先保存需要保留资料，避免拿真实未备份项目试验。

  4. 04

    核对应保留和应清除的内容，对照清单核对保留、删除和重新注入项，既不能丢项目也不能残留不应传播的秘密。

怎样判断已完成

重建结果符合既定数据边界。

容易忽略的地方

把所有状态都写进镜像以求方便。

示例与记录方式

测试容器约定/workspace持久、/tmp临时、认证运行时注入。重建后逐项检查项目保留、临时文件清除及无个人令牌进入镜像，数据既不能无意丢失，也不能为方便而全部永久保存。
