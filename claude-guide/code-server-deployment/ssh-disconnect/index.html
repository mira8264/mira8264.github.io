SSH断开后Claude Code任务怎么办

SSH窗口关闭后进程是否保留取决于启动方式，先记录任务及持久化方案，再通过小任务验证断线恢复而非凭经验推断。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    确认任务运行方式和会话宿主，交互终端与后台任务的行为可能不同。

  2. 02

    保存当前项目状态与任务记录，未保存内容应先落到受控项目文件。

  3. 03

    使用组织允许的会话保持方案，使用前先理解中断及日志保存方式。

  4. 04

    重连后核对进程与实际产物，重新连接不能只根据窗口标题判断。

怎样判断已完成

断线后的状态可以被重新识别。

容易忽略的地方

不要认为所有SSH窗口关闭后进程都会自动保留；使用组织认可的保持及恢复方式。

示例与记录方式

示例断线检查先记录终端宿主和任务进程标识，再执行一次允许的短测试。重连后根据进程与产物判断完成状态，不盲目重复运行已成功的任务。
