Claude Code Skills 怎么用

Claude Code Skills适合整理反复执行的任务程序。本专题从任务范围和触发描述开始，逐步核对目录、元数据、参数、参考附件、权限与评估集，再处理团队分享、同名冲突和旧技能停用。重点是让技能何时适用、输出什么、如何检查都能明确表达，而不是把所有知识堆进同一个文件。

GUIDE / 01

Claude Code何时用Skills而非项目规则

代码风格是项目事实而发布检查是流程。识别有明确输入输出的程序，通过用一项小任务验证选择确认技能负责程序而项目规则保留事实。

GUIDE / 02

Claude Code技能任务范围怎么写

技能只负责检查文档链接而不负责发布网站。说明适用场景和不适用范围，通过让同事判断何时应调用确认读者能清楚判断技能是否适用。

GUIDE / 03

Claude Code技能描述如何避免误触发

翻译技能不应被普通代码审查触发。在描述中写清任务和触发条件，通过观察不同提问下是否被调用确认适用与不适用样例能被区分。

GUIDE / 04

Claude Code技能目录放置核对

团队共享技能与个人试验技能分开放置。按官方目录结构创建文件，通过在目标项目查看是否可用确认技能出现在预期作用域中。

查看步骤与验收方法 →
GUIDE / 05

Claude Code SKILL.md元数据检查

描述中含冒号时注意YAML字符串格式。检查文件头部格式与缩进，通过通过最小调用验证加载确认元数据被识别且没有解析警告。

GUIDE / 06

Claude Code技能步骤如何写成可执行流程

审查技能先限定差异再定位问题再报告。在关键节点定义判断条件，通过以真实小样本完整走一次确认每步都有可观察的完成结果。

GUIDE / 07

Claude Code技能参数怎么设计

文件路径含空格时需要明确作为一个参数处理。区分必填可选和默认值，通过测试缺少或多余参数的情况确认参数错误能被明确发现并询问。

GUIDE / 08

Claude Code技能参考文件如何拆分

审查指南只在涉及数据库时读取SQL清单。将长规则和示例分成附件，通过检查相对路径能找到文件确认必要参考能按任务正确读取。

Claude Code技能工具权限核对

生成报告不需要同时具备发送邮件权限。按当前版本核对权限字段，通过检查超出范围时是否停下确认工具能力与技能用途相匹配。

GUIDE / 10

Claude Code技能手动调用测试

链接检查技能需要输出坏链清单和位置。用明确参数运行一次，通过记录被跳过步骤的原因确认手动调用能完成规定交付。

GUIDE / 11

Claude Code技能自动触发测试

格式化JSON问题不应触发完整发布流程。加入边界和相似非适用任务，通过收窄描述后重复比较确认触发范围与设计意图一致。

GUIDE / 12

Claude Code技能示例如何挑选

数据清洗技能加入重复记录与缺失字段。给出可核对的正确结果，通过说明示例哪些内容可变确认使用者能从示例理解输出标准。

GUIDE / 13

Claude Code技能评估集怎么建

十条文档审查样本包含失效与有效链接。为每项写通过与失败条件，通过保留退步案例而非只留成功确认版本变化有可解释质量证据。

Claude Code技能版本更新记录

新增一个阻止自动发布的确认步骤需记录。把技能和示例一起纳入版本管理，通过保留可回退的已通过版本确认能够定位效果变化对应哪次修改。

GUIDE / 15

Claude Code同名Skills冲突处理

个人与项目目录都有同名review技能。按官方优先级核对当前来源，通过在目标项目重测调用结果确认调用名称能对应唯一预期内容。

GUIDE / 16

Claude Code外部技能使用前审查

一个排版技能不应要求读取浏览器登录资料。检查网络目标与凭证访问，通过只批准完成任务必要操作确认没有未经理解的外部发送步骤。

Claude Code技能团队分发清单

示例使用相对项目路径而非某个人目录。列出依赖与支持环境，通过明确反馈和维护负责人确认新环境可按说明完成同一任务。

GUIDE / 18

Claude Code停用旧技能怎么做

发布流程升级后旧技能仍可能自动发送通知。告知替代技能与行为变化，通过测试旧名称不会误触发确认旧流程已停止且替代流程可用。

Claude Code技能没有生效如何定位

技能存在但描述没有涵盖真实提问方式。检查元数据和作用域，通过再检查描述触发和运行步骤确认问题被定位到发现触发或执行阶段。
