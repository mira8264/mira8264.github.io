Claude Code怎样进行保行为重构

用当前行为、调用方和回归样例解决本篇问题：先固定关键行为，再分小步调整结构并运行原测试。重点防止把功能变更混进重构导致难以追查，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备当前行为、调用方和回归样例；保存关键接口、输出样本与调用方假设，将功能变化与结构调整分成不同任务。

  2. 02

    先固定关键行为，再分小步调整结构并运行原测试；先以原测试固定行为，再一次只调整一个结构边界，保留每一步可回退的差异。

  3. 03

    比较重构前后的同一输入结果，检查排序、错误类型和副作用等容易被忽略的契约。

  4. 04

    验收接口和输出保持约定行为：外部可见接口与输出符合原约定，结构变化未夹带新功能或删除边界处理。

怎样判断已完成

外部可见接口与输出符合原约定，结构变化未夹带新功能或删除边界处理。

容易忽略的地方

把功能变更混进重构导致难以追查。

示例与记录方式

示例重构：将重复校验提取到函数，但对同一组正常和错误输入，返回值与错误类型都保持原约定。 把重复校验抽成函数时，用同一批有效和无效输入对照，错误消息或状态变化需要单独评估。
