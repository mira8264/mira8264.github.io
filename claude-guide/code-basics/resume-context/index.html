Claude Code继续旧任务先查什么

用旧会话要点、仓库现状和新变更解决本篇问题：恢复讨论前先比较当前文件状态，确认旧假设是否仍成立。重点防止照旧会话操作覆盖别人后来修改，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备旧会话要点、仓库现状和新变更；先读取当前分支、未提交差异与相关文件，核对旧会话引用是否仍存在。

  2. 02

    恢复讨论前先比较当前文件状态，确认旧假设是否仍成立；将旧计划中的事实与仓库现状并排比较，别人已修改的部分不能按旧结论覆盖。

  3. 03

    重新执行旧任务的最小复现，若症状已改变，先重建问题定义再采用后续修复计划。

  4. 04

    验收继续的计划基于当前仓库内容：继续操作依据当前文件和实际复现，旧会话中失效的路径与假设已被明确剔除。
