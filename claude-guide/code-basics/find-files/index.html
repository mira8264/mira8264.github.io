Claude Code怎样定位功能文件

用功能名称、现象与已知入口解决本篇问题：让工具查找相关文件并解释关联，定位后再决定修改范围。重点防止找到同名文件就直接编辑而未确认用途，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备功能名称、现象与已知入口；给出界面动作、接口路径或错误现象，补一个已知调用入口以缩小搜索范围。

  2. 02

    让工具查找相关文件并解释关联，定位后再决定修改范围；让工具先搜索符号与引用，列候选文件及为什么有关，再选实际执行路径。

  3. 03

    沿调用关系核对候选文件是否被当前入口加载，排除测试夹具与废弃实现后再编辑。

  4. 04

    验收找到的路径与实际功能调用相符：最终修改路径属于实际执行链，未因同名文件或旧模块造成无效修复。

怎样判断已完成

最终修改路径属于实际执行链，未因同名文件或旧模块造成无效修复。

容易忽略的地方
