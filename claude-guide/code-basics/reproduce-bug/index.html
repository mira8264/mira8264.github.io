Claude Code排错前提供什么

用复现命令、错误原文和最小输入解决本篇问题：先跑原有复现步骤保留失败现象，再提出修复假设。重点防止只贴错误最后一行让工具猜环境，输出应能回到原始输入核对。

操作步骤

  1. 01

    准备复现命令、错误原文和最小输入；保存完整复现命令、输入与错误原文，同时注明期望行为和最近变更。

  2. 02

    先跑原有复现步骤保留失败现象，再提出修复假设；要求先执行原始复现步骤并记录失败，再基于证据提出一个可验证的修复假设。

  3. 03

    将失败缩小为最小用例，保留能触发问题的必要条件，避免整批改动掩盖原因；注意避免只贴错误最后一行让工具猜环境。

  4. 04

    验收修改前确实能重现同一问题：修复前用例确实失败，修复后同一输入通过，错误变化能由具体代码解释。

示例与记录方式

示例报告：运行测试时订单数量为0会报错；提交复现命令、输入和完整错误栈，让修复围绕同一个现象展开。 输入为空数组时导出失败，先保留失败堆栈与命令，再确认修复没有改变正常数组输出。
