Claude Code怎样从正确目录开始

用仓库位置、项目说明和当前分支解决本篇问题：先确认终端所在目录和版本状态，再让工具概览项目结构。重点防止在用户主目录启动后意外读取无关资料，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备仓库位置、项目说明和当前分支；记录仓库的完整路径与当前分支，查看是否存在未提交的人工改动再启动工具。

  2. 02

    先确认终端所在目录和版本状态，再让工具概览项目结构；第一条请求仅做目录概览，要求指出项目根目录与主要入口，不先修改文件。

  3. 03

    选取一个已知源文件检查其路径与项目说明是否一致，发现根目录错误就退出重新定位。

  4. 04

    验收讨论与修改都发生在目标仓库内：工具引用的文件都位于目标仓库，原有未提交改动可与本次工作清楚区分。

怎样判断已完成

工具引用的文件都位于目标仓库，原有未提交改动可与本次工作清楚区分。

容易忽略的地方

在用户主目录启动后意外读取无关资料。

示例与记录方式

示例检查：终端目录显示个人下载文件夹，但目标仓库在D盘项目目录。先进入仓库，再请工具解释文件结构。 记录包含仓库路径、分支与未提交文件清单，首次会话只读目录，不请求立即重构。
