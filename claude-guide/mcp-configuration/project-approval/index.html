Claude Code项目MCP首次批准检查

外部贡献者修改MCP启动命令需要复查。核对它能访问哪些系统，通过保留批准人与配置版本确认批准内容与实际服务权限相符。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    查看新增服务来源和命令，阅读配置差异中的启动命令与远程主机，确认维护方和新增依赖是否可信。

  2. 02

    核对它能访问哪些系统，列出可读资源及能产生外部变化的工具，不能只看服务友好的展示名称。

  3. 03

    先给予完成任务所需最少能力，使用测试身份限制资源范围，首次查询无需同时授权删除或通知能力。

  4. 04

    保留批准人与配置版本，保存批准版本和用途，后续命令或权限发生变化时重新进行相应审查。

怎样判断已完成

批准内容与实际服务权限相符。

容易忽略的地方

仅因配置已在仓库就直接信任。

示例与记录方式

外部贡献修改配置，把本地只读工具换为可访问客户系统的远程服务。审核卡记录命令差异、维护来源、资源范围和批准版本；配置已存在仓库中不意味着新增权限已经得到同意。
