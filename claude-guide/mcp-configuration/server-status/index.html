Claude Code MCP状态页怎么读

连接已成功但配置变量仍显示未解析。查看当前作用域与工具数量，通过保存不含秘密的错误摘要确认每个异常都能对应具体阶段。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    检查连接和鉴权分别是否成功，将连接、授权与工具发现分开查看，某阶段成功不能代替其他阶段通过。

  2. 02

    查看当前作用域与工具数量，确认当前项目与服务名称，工具数量只作线索，不作为权限正确的唯一证据。

  3. 03

    对照配置警告定位问题，从警告对应的变量、端点或角色逐项定位，避免同时修改全部配置失去对照。

  4. 04

    保存不含秘密的错误摘要，记录服务名、阶段和错误类型即可，去掉令牌及客户资料后再用于求助。

怎样判断已完成

每个异常都能对应具体阶段。

容易忽略的地方

只看绿色图标忽略配置警告。

示例与记录方式

状态示例为连接完成、授权完成、工具发现失败，并附变量未解析警告。诊断表按阶段填状态与证据，先修复对应配置；绿色连接图标不能替代工具已经能够使用的验收结论。
