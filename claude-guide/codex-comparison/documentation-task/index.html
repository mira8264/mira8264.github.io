Claude Code与Codex文档任务评估

订阅取消接口不能被描述成删除账户。要求标注无法确认的信息，通过让新读者照文档完成小任务确认读者能复现且没有杜撰接口。

操作步骤

  1. 01

    提供权威契约与真实样例，提供真实接口契约、返回样本和错误码来源，禁止自行补造参数。

  2. 02

    要求标注无法确认的信息，缺少文档依据的内容标为待确认，不把合理猜测写成产品事实。

  3. 03

    逐项核对参数和错误码，逐项比对字段名称、必填性和异常条件，检查例子是否能被契约接受。

  4. 04

    让新读者照文档完成小任务，请不了解项目的人按文档完成无害任务，记录卡住和误解的位置。

怎样判断已完成

读者能复现且没有杜撰接口。

容易忽略的地方

文档更长就认为更完整。

示例与记录方式

契约说明取消订阅仅阻止下期续费，并不删除账户。文档验收样本要求读者定位操作与结果，若生成说明把取消写成销户，应登记为事实错误，即使其他段落完整也不能直接发布。
