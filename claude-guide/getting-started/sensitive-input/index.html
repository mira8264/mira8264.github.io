Claude提问前怎样整理敏感资料

用拟发送文本及必须保留的业务含义解决本篇问题：先用占位符替换凭证与个人信息，再检查剩余内容是否足够。重点防止只遮盖姓名却保留完整密钥或账户信息，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备拟发送文本及必须保留的业务含义；先扫描姓名、邮箱、订单号和凭证，再判断任务真正需要哪些字段。

  2. 02

    先用占位符替换凭证与个人信息，再检查剩余内容是否足够；为同一个对象使用一致占位符，保留关系与单位而删除可识别内容。

  3. 03

    把脱敏文本当成新资料阅读，检查是否仍能完成分析，并再次搜索密钥特征；注意避免只遮盖姓名却保留完整密钥或账户信息。

  4. 04

    验收脱敏后任务仍可理解且凭证未出现：样本可用于理解问题，真实密码、密钥和不必要的个人标识均没有出现。

容易忽略的地方

只遮盖姓名却保留完整密钥或账户信息。

示例与记录方式
