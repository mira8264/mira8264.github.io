Claude怎样按固定表头输出

用字段定义、示例行与空值规则解决本篇问题：先提供表头与一条正确样例，要求缺失字段标记待确认。重点防止表格漂亮但字段含义与需求不同，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备字段定义、示例行与空值规则；为每一列写明含义、单位及允许空值，提供一条完整正确样例。

  2. 02

    先提供表头与一条正确样例，要求缺失字段标记待确认；说明字段不足时用什么占位词，禁止模型自行新建相似字段。

  3. 03

    先用两行数据测试表头，再检查行列对齐和单位，确认后处理剩余资料；注意避免表格漂亮但字段含义与需求不同。

  4. 04

    验收各行字段完整且没有自行改名：每行字段数一致，空值有统一标记，列名与业务定义没有发生漂移。

怎样判断已完成

每行字段数一致，空值有统一标记，列名与业务定义没有发生漂移。

容易忽略的地方

表格漂亮但字段含义与需求不同。

示例与记录方式

示例表头：问题、已知事实、缺少资料、负责人。输入中没有负责人时填写待确认，不根据部门名称推测人员。 先生成两行小表验证结构，缺失套餐价格填待确认，而不是填零造成免费误解。
