远程开发时编辑器和Claude Code在哪运行

本地编辑器窗口、远端扩展宿主和容器可能在不同位置运行，主机与目录确认能说明哪一步真正读取或修改文件。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    画出本地编辑器与远程终端位置，不要把编辑器窗口位置当执行位置。

  2. 02

    在终端确认主机和工作目录，远程主机名与目录应同时可观察。

  3. 03

    核对扩展运行在本地还是远端，容器也应作为独立执行环境标记。

  4. 04

    用测试文件观察实际修改位置，测试文件不包含真实客户资料。

怎样判断已完成

开发者能指出每个动作的执行主机。

容易忽略的地方

不要因为窗口在本地就认定代码也在本地执行；用主机信息和测试文件确定执行侧。

示例与记录方式
