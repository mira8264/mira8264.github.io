SSH登录Linux运行Claude Code的准备

本机浏览器无法访问远端本地回调时需按官方说明处理。区分本地浏览器和远端进程，通过断开前保存任务与工程状态确认认证和操作都对应正确远端环境。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    确认SSH会话用户与工作目录，记录登录用户、主机与目录，命令执行状态应以远端实际环境为准。

  2. 02

    区分本地浏览器和远端进程，浏览器可能在本机而CLI在服务器，登录页可打开不代表回调能够到达远端。

  3. 03

    按官方认证流程处理回调，使用当前官方给出的认证路径处理环境差异，不公开登录代码让其他人代为认证。

  4. 04

    断开前保存任务与工程状态，断开前保存文件与检查点，恢复后先看进程和磁盘状态避免重复运行任务。

怎样判断已完成

认证和操作都对应正确远端环境。

容易忽略的地方

远端出现登录链接就复制给其他人代登录。

示例与记录方式

远端为host-a，浏览器在个人笔记本。认证记录写两处位置及回调状态，不保存登录代码；断开后再连先查项目差异与任务进程，不能因为终端窗口消失就重做所有已执行操作。
