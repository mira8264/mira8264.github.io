终端任务转到云会话前准备什么

从终端接续到云会话之前，分支、未提交修改和上下文都需要确认转移方式，旧说明不应被当作当前产品行为保证。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    记录分支和未提交修改状态，避免未提交改动遗漏或混入其他任务。

  2. 02

    核对当前官方转移方式与限制，不得根据旧文章假设所有状态可转移。

  3. 03

    同步任务需要的非敏感上下文，包括任务目标测试命令和停止条件。

  4. 04

    到云端后先核对文件与工作目录，确认未把旧工作副本当成当前代码。

怎样判断已完成

转移后的代码状态与任务说明一致。

容易忽略的地方

不要假定本地未提交文件一定会随会话转移；转移前检查未提交文件处理方式。

示例与记录方式

示例迁移前记录分支feature/demo、源提交和未提交文件列表，转移后在云端核对对应内容。凡未包含的本地资料，另行决定是否有权同步。
