云会话为什么看不到本地文件

云端程序不会因为提示中出现本地路径就拿到文件，必要输入需经过授权同步，并在实际执行目录复核内容版本。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    确认文件实际存在哪个设备，本机路径与云主机路径是不同命名空间。

  2. 02

    查看云环境已有的仓库与目录，确认任务挂载的是正确分支与版本。

  3. 03

    只同步被允许处理的必要文件，不将整个用户家目录当作输入上传。

  4. 04

    在云端核对路径和文件版本，可用文件大小或摘要比较输入内容。

怎样判断已完成

任务输入已实际出现在执行环境。

容易忽略的地方

不要在提示里写本地路径就假定云端可以读取；先经授权将必要文件送达云环境。

示例与记录方式

示例用户本机有C:\notes\brief.md，但云任务只看到仓库目录。先确认资料能被上传或同步，再在云环境核对实际文件路径，不能只引用本地地址。
