Claude API 价格

API预算由实际模型、输入输出、缓存、工具及调用渠道共同决定，最终账单还需要考虑币种、税费和账期。本专题从请求级用量记录到月度对账，提供可复算的预算方法与脱敏日志建议。当前单价查官方文档，预估不能替代实际账单，也不能把客户端超时简单理解为没有产生处理费用。
