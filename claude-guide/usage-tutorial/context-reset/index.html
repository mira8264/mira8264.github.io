Claude什么时候应新开对话

用当前目标、历史条件和新的独立任务解决本篇问题：任务无关时另开对话，相关任务先整理仍有效的上下文。重点防止把不同项目长期塞进一条对话，输出应能回到原始输入核对。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    准备当前目标、历史条件和新的独立任务；将当前对话中仍有效的限制整理为短清单，删除旧客户与过期数据。

  2. 02

    任务无关时另开对话，相关任务先整理仍有效的上下文；新任务若资料或责任主体不同，另建对话并仅带入必要规则，不复制全部历史。

  3. 03

    检查新结果中的名称、金额和期限是否来自当前输入，发现旧事实就回查上下文。

  4. 04

    验收新任务没有混入旧客户和旧条件：新任务不出现旧客户事实，必要格式规则仍保留，资料边界可清楚解释。

怎样判断已完成

新任务不出现旧客户事实，必要格式规则仍保留，资料边界可清楚解释。

容易忽略的地方

把不同项目长期塞进一条对话。

示例与记录方式

示例判断：正在讨论服务器迁移时突然需要写员工入职邮件，应另开对话，避免迁移日期和客户资料进入新邮件。 旧任务是客户A的月费，下一任务是客户B的年费；仅复用表头，不带入A的价格信息。
