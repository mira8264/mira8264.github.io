Claude Code与Cursor跨文件改动验收

增加字段时模型与序列化和前端都要检查。提供可检查的验收条件，通过核查调用方与测试是否同步确认相关模块行为保持一致。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    写清受影响模块和契约，列出数据模型、接口与界面的对应关系，说明新增字段语义。

  2. 02

    提供可检查的验收条件，把默认值、序列化与展示写成可检查条件，而非只说字段可用。

  3. 03

    跟踪每个文件修改理由，逐个审查文件存在修改的必要性，注意遗漏的调用方与兼容代码。

  4. 04

    核查调用方与测试是否同步，用完整请求经过相关模块，并确认旧输入仍按原契约处理。

怎样判断已完成

相关模块行为保持一致。

容易忽略的地方

多个文件被修改就认为任务完整。

示例与记录方式

假设给用户模型增加display_name字段，涉及存储、API与页面。验收表逐层记录空值、旧数据默认值和返回字段；只改模型却遗漏序列化，即使修改了多个文件也不是完整交付。
