Claude Code 额度用完怎么办

Code容量中断后，先保存改动和任务证据，再依据官方恢复提示安排剩余工作，比反复重试更便于继续交付。本专题覆盖交接摘要、人工诊断、任务范围、预算选择和恢复后的验证，帮助避免重复修改与无意付费。等待、计划调整及获批付费路径需要结合当前规则判断，不采用共享身份规避限制。
