Code无法继续响应时哪些检查可以先人工完成

模型暂不可用时可以先人工复现、整理最小输入与测试错误，形成下一次可直接使用的证据，减少重复环境探索。

Mira 指南编辑组资料核对：2026-10-23返回专题中心

操作步骤

  1. 01

    保存已有输出和代码差异，列出模型尚未验证的假设与本地可以运行的测试。

  2. 02

    在自己授权的环境中执行既有测试或静态检查，记录真实错误而不是猜测修复。

  3. 03

    将检查结果整理成简明交接，等Code恢复后只处理仍然未解决的问题。

  4. 04

    用本地复现步骤确认错误仍存在，保存必要日志片段和实际结果；容量恢复后只提交这些已核实材料。

怎样判断已完成

人工检查结果已形成下一轮输入。

容易忽略的地方

不要为了等待模型而跳过可独立完成的验证，也不要把未运行测试标记为已通过。

示例与记录方式

示例离线工作：先本地复现错误、整理最小输入并查阅测试失败位置，写下实际结果。容量恢复后只提交必要证据，减少模型重复探索环境的消耗。
