如何减少Claude Code重复读取大目录

减少重复读取应先限定相关目录与调用位置，再按依赖证据扩展，保留已读摘要而非每轮重新扫描整库。

操作步骤

  1. 01

    先指出目标模块、相关文件与可忽略的构建产物，说明本次任务实际边界。

  2. 02

    让Code从搜索和必要片段开始阅读，只有证据指向其他范围时再扩展。

  3. 03

    检查任务是否仍能理解调用关系，保留需要补读的依赖而不是一律禁止。

  4. 04

    用问题调用链检查是否遗漏必要文件，新增依赖只补对应内容；记录已核对范围，供下一轮避免重复读取。

容易忽略的地方

只限制读取数量却不给路径与背景会导致猜测，节省输入必须同时保证证据充分。
