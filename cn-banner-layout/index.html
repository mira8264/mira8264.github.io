先把任务说清楚

准备资料 → 约定结果 → 检查输出

01 / 输入

准备哪些资料

横幅用途、文案、主视觉、桌面与手机尺寸。把已确认事实与仍需补充的信息分开，保留原始资料供后续核对。

02 / 交付

应该得到什么

布局草案、安全区、移动端裁切说明。先约定最终交付形式，再决定使用哪个工具，避免生成完才发现不能直接使用。

03 / 约束

这一步尤其重要

正文和按钮必须处于安全区，不能只看桌面完整画布。

任务示例

把要求放进具体情境

制作海外服务器推广横幅，桌面图采用左右结构，手机裁切后仍能看见产品主体和行动按钮。

常见失误

主视觉好看，但手机版标题被裁掉。将这一问题放进样例检查中，比只要求结果更专业更容易执行。

验收重点

不同尺寸的信息完整率

  • 对照原始资料检查重要事实和限制。
  • 检查交付中是否包含：布局草案、安全区、移动端裁切说明。
  • 确认规则已满足：正文和按钮必须处于安全区，不能只看桌面完整画布。
  • 记录失败样例，便于下一次对比改进。

常见问题

开始前最少需要准备什么？

至少准备横幅用途，再补充文案、主视觉、桌面与手机尺寸。资料缺失时先把问题列出来，不让工具代替你虚构事实。

怎样判断结果是否合格？

重点看不同尺寸的信息完整率，并检查是否出现主视觉好看，但手机版标题被裁掉。先拿一份可以人工核对的小样本试用，再扩大任务量。

需要一次接入所有工具吗？

不需要。先确认任务需要哪些环节，再选择生成、编辑、校验或部署工具。功能、费用和授权条件请以各产品官方页面为准。
