先把任务说清楚

准备资料 → 约定结果 → 检查输出

01 / 输入

准备哪些资料

原图、展示尺寸、透明需求、体积目标。把已确认事实与仍需补充的信息分开，保留原始资料供后续核对。

02 / 交付

应该得到什么

导出版本、尺寸记录、质量检查清单。先约定最终交付形式，再决定使用哪个工具，避免生成完才发现不能直接使用。

03 / 约束

这一步尤其重要

不要把放大后的文件直接压缩到目标体积，先确定实际展示尺寸再导出。

把要求放进具体情境

常见失误

体积达标但重要细节已经模糊。将这一问题放进样例检查中，比只要求结果更专业更容易执行。

验收重点

可读性与文件体积的平衡结果

  • 对照原始资料检查重要事实和限制。
  • 检查交付中是否包含：导出版本、尺寸记录、质量检查清单。
  • 确认规则已满足：不要把放大后的文件直接压缩到目标体积，先确定实际展示尺寸再导出。
  • 记录失败样例，便于下一次对比改进。

常见问题

开始前最少需要准备什么？

至少准备原图，再补充展示尺寸、透明需求、体积目标。资料缺失时先把问题列出来，不让工具代替你虚构事实。

怎样判断结果是否合格？

重点看可读性与文件体积的平衡结果，并检查是否出现体积达标但重要细节已经模糊。先拿一份可以人工核对的小样本试用，再扩大任务量。

需要一次接入所有工具吗？

不需要。先确认任务需要哪些环节，再选择生成、编辑、校验或部署工具。功能、费用和授权条件请以各产品官方页面为准。
